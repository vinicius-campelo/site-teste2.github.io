# 🏗️ ALTO NÍVEL · Construtora e Serviços Gerais

Site institucional **single page** desenvolvido para a empresa **Alto Nível Construtora e Serviços Gerais**.

![Alto Nível](https://img.shields.io/badge/Status-Em%20desenvolvimento-yellow)
![License](https://img.shields.io/badge/License-MIT-blue)

---

## 🎯 Sobre o Projeto

Site moderno, responsivo e otimizado para apresentar os serviços da Alto Nível, com foco em:

- **Identidade visual** forte (azul, amarelo e branco)
- **Experiência do usuário** fluida (SPA com scroll suave)
- **Conversão** com formulário de orçamento e WhatsApp integrado
- **Informações completas** sobre serviços, missão, visão e valores
